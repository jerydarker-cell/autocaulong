# Badminton Vinh AI Automation Pro

Bản nâng cấp toàn diện cho app cầu lông TP Vinh, tập trung vào AI tự động hóa chuyên nghiệp nhưng mặc định không tốn API.

## AI Automation mới
- AI Automation Center: chẩn đoán sức khỏe kinh doanh, gợi ý tăng trưởng.
- AI Task Manager: AI tự tạo task vận hành từ dữ liệu thực tế.
- AI Marketing Automation: tạo chiến dịch Facebook/Zalo/App Notification.
- AI Pricing & Court Ops: gợi ý giá giờ hot/thấp điểm và checklist vận hành sân.
- AI CRM & Matchmaking: phân nhóm khách, gợi ý chăm sóc và ghép kèo.
- AI Workflow Builder: tạo rule tự động hóa không cần code.
- AI Chat Pro Offline: hỏi đáp vận hành không tốn API.

## Chạy app
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Lưu ý
Dữ liệu sân/HLV/giá/voucher vẫn là dữ liệu mẫu. Khi public thật, hãy thay bằng dữ liệu sân thật ở TP Vinh.
