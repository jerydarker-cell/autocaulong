# Badminton Vinh AI Automation Ultra

Ứng dụng Streamlit riêng cho cầu lông TP Vinh, nâng cấp AI tự động hóa toàn diện.

## Điểm mới so với AI Automation Pro
- AI Ultra Command Center: trung tâm điều hành tự động hóa.
- AI Auto Scheduler: tạo lịch tự động nhắc khách, voucher, báo cáo, combo.
- AI Playbook Lab: playbook tăng trưởng/vận hành/CRM/marketplace.
- AI Inventory & Finance: phân tích sản phẩm, combo, doanh thu dự báo.
- AI Risk Guard: kiểm tra rủi ro trùng lịch, thiếu dữ liệu, feedback, public safety.
- AI Ultra Settings: cấu hình offline-first, không tốn API mặc định.

## Chạy app
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Lưu ý
Dữ liệu sân/giá/HLV/voucher đang là dữ liệu mẫu. Cần thay bằng thông tin thật trước khi public.
