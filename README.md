# Badminton Vinh Pro Max

Ứng dụng Streamlit riêng biệt cho cầu lông tại TP Vinh.

## Tính năng chính
- Đặt lịch sân, kiểm tra trùng lịch.
- Chợ mua bán dụng cụ cầu lông.
- Tìm người chơi / tìm kèo.
- HLV, lớp học, giáo án luyện tập.
- Giải đấu, hội viên, check-in.
- Pro Max Center, Chủ sân Portal, CRM khách hàng.
- Ví điểm & Loyalty, QR check-in demo.
- Đặt sân thông minh, combo thuê vợt/cầu.
- Xuất báo cáo CSV/JSON.
- Trợ lý vận hành offline không tốn API.
- Health Check, Admin mini, backup.

## Chạy local
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Ghi chú
Dữ liệu sân/HLV/giá là dữ liệu mẫu. Trước khi public cần thay bằng dữ liệu thật tại TP Vinh.
